# Linear (Barry bag)

Linear issue tracking — query, create, and manage tickets, projects, and cycles.

## Tools

- `ticket_get` — get a ticket by identifier with full details
- `ticket_list` — list tickets with filters (team, assignee, status, label, project)
- `ticket_search` — full-text search across all tickets
- `ticket_create` — create a new ticket or sub-issue
- `ticket_update` — update a ticket's status, assignee, priority, title, or labels
- `ticket_add_comment` — add a markdown comment to a ticket
- `ticket_list_comments` — get all comments on a ticket
- `ticket_list_statuses` — list workflow statuses for a team
- `ticket_list_teams` — list all teams in the workspace
- `ticket_list_labels` — list available labels
- `ticket_get_project` — get project details by name
- `ticket_get_cycle` — get cycle/sprint info for a team
- `ticketing_status` — check Linear API connectivity and workspace info
